# Lartiska — L'art qui transforme vos espaces

Site vitrine de **Lartiska**, entreprise sénégalaise de peinture moderne, plafonnage esthétique, carrelage design et décoration artistique.

## 🌍 Réalisations
Sénégal · Gambie · Mauritanie

## 🛠️ Stack
HTML5 · CSS3 · JavaScript vanilla · GSAP (ScrollTrigger) · Vidéos full-screen

## 📄 Fichiers
- `index.html` — site complet (single-page)
- `Lartiska.mp4`, `V1.mp4`, `V4.mp4`, `V5.mp4`, `V6.mp4` — vidéos d'ambiance
- `villes/` — photos des chantiers par ville
- `flyers1.html`, `flyers2.html`, `flyers3.html` — maquettes de flyers imprimables

## 🚀 Lancer en local
Ouvrir `index.html` avec Live Server (VS Code) ou tout autre serveur statique.
